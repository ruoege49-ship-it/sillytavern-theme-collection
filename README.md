# SillyTavern 主题合集

一组可导入 SillyTavern 的界面主题，以及“我在看着你”主题的 Tavern Helper 配套脚本。

## 仓库结构

- `themes/`：19 个 SillyTavern 主题 JSON
- `tavern-helper/`：Tavern Helper 配套脚本

## 使用方法

1. 下载 `themes/` 中需要的 JSON 文件。
2. 在 SillyTavern 的用户设置中导入主题。
3. 使用“我在看着你”时，可在 Tavern Helper 中导入 `tavern-helper/watching-you-tavern-helper.json`，启用随机背景与红色问号效果。

配套脚本依赖“我在看着你”主题中定义的背景变量，应与该主题一起使用。
